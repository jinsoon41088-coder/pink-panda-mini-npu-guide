📚 1. 입력 패턴이란 무엇일까요?

입력 패턴은 컴퓨터가 어떤 모양인지 판단해야 하는 데이터입니다.

사람은 그림을 보고 모양을 구별하지만, 컴퓨터는 그림을 숫자로 표현하여 계산합니다.

■ 색칠된 칸 = 1
□ 색칠되지 않은 칸 = 0

X 모양

🔍 2. 필터란 무엇일까요?

이번 미션에서 필터는 입력 패턴과 비교하기 위해 준비한 기준 모양입니다.

📝 입력 패턴 = 맞혀야 하는 문제
📖 필터 = 비교할 기준 모양

입력 패턴을 십자가 필터와 X 필터에 각각 비교하여 MAC 점수를 계산합니다.

🧮 3. 유사도 점수 계산 원리

입력 패턴과 필터의 같은 위치에 있는 숫자끼리 곱합니다.

곱셈 결과를 모두 더하면 MAC 점수가 됩니다.

① 같은 위치의 숫자 찾기
② 두 숫자 곱하기
③ 곱셈 결과 누적하기
④ 두 필터의 최종 점수 비교하기
⑤ 모양 판정하기

이번 미션에서는 MAC 점수가 더 높은 필터를 선택합니다.

단, MAC 점수는 확률이나 백분율이 아니며 모든 상황에서 모양의 유사도를 정확하게 나타내는 것은 아닙니다.

💻 5. Python 코드로 이해하기

def mac(pattern, filter_data):
    score = 0.0
    n = len(pattern)

    for i in range(n):
        for j in range(n):
            score += pattern[i][j] * filter_data[i][j]

    return score

첫 번째 for문은 행을 반복하고, 두 번째 for문은 열을 반복합니다.

같은 위치의 숫자를 곱한 결과를 score에 계속 더합니다.

3×3 배열에서는 필터 하나당 총 9회의 MAC 연산을 수행합니다.

Q. 입력 패턴이란 무엇인가요?

A. 컴퓨터가 어떤 모양인지 판단해야 하는 입력 데이터입니다.

Q. 필터란 무엇인가요?

A. 입력 패턴과 비교하기 위해 준비한 기준 데이터입니다.

Q. MAC 점수는 어떻게 계산하나요?

A. 입력 패턴과 필터의 같은 위치에 있는 숫자끼리 곱하고 그 결과를 모두 더합니다.

Q. 두 필터의 점수가 같으면 어떻게 하나요?

A. 이번 미션에서는 점수 차이가 epsilon보다 작으면 UNDECIDED로 판정합니다.
