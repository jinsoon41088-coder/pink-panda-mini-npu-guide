성능 분석은 프로그램이 얼마나 많은 계산을 하고 실행하는 데 얼마나 시간이 걸리는지 확인하는 과정입니다.

📐 3. 시간 복잡도 O(N²)란?

시간 복잡도는 입력 데이터의 크기가 커질 때 알고리즘의 작업량이 얼마나 증가하는지 나타내는 방법입니다.

N = 정사각형 배열의 한 변의 길이
N × N = N²
O(N²)

배열의 가로와 세로 길이가 각각 N이고 모든 칸을 한 번씩 계산한다면 총 N²번의 MAC 연산이 필요합니다.

배열의 한 변이 2배가 되면
연산 횟수는 2 × 2 = 4배

배열의 한 변이 3배가 되면
연산 횟수는 3 × 3 = 9배

따라서 이 방식의 MAC 연산 시간 복잡도는 O(N²)입니다.

O(N²)는 정확한 실행 시간을 의미하는 것이 아니라 입력 크기에 따른 작업량의 증가 형태를 나타냅니다.

💻 6. Python 이중 반복문으로 이해하기

def mac(pattern, filter_data):

    n = len(pattern)

    score = 0.0

    for i in range(n):

        for j in range(n):

            score += pattern[i][j] * filter_data[i][j]

    return score

코드의 의미

n = len(pattern)
배열의 행 개수를 확인합니다.

score = 0.0
계산 결과를 저장할 점수를 초기화합니다.

for i in range(n)
바깥 반복문은 행을 이동합니다.

for j in range(n)
안쪽 반복문은 열을 이동합니다.

score +=
각 위치의 두 값을 곱하고 이전 계산 결과에 더합니다.

return score
모든 계산이 끝나면 최종 점수를 반환합니다.

바깥 반복문: N번
안쪽 반복문: N번

전체 MAC 연산: N × N = N²번

위 코드는 입력과 필터가 동일한 크기의 유효한 정사각형 배열이라는 전제의 예시입니다.

⏱️ 7. 실행 시간은 어떻게 측정할까요?

프로그램을 한 번만 실행하면 컴퓨터의 상태에 따라 측정 결과가 달라질 수 있습니다.

따라서 같은 계산을 여러 번 실행하고 평균 실행 시간을 구합니다.

① 입력 배열과 필터 준비
② 시작 시간 기록
③ MAC 연산 실행
④ 종료 시간 기록
⑤ 실행 시간 계산
⑥ 10회 반복
⑦ 평균 실행 시간 계산

Python 실행 시간 측정 예시

import time

def measure_time(pattern, filter_data):

    times = []

    for _ in range(10):

        start = time.perf_counter()

        mac(pattern, filter_data)

        end = time.perf_counter()

        elapsed_ms = (end - start) * 1000

        times.append(elapsed_ms)

    average = sum(times) / len(times)

    return average

time.perf_counter()는 실행 시간을 측정하는 데 적합한 Python 함수입니다.

초 단위 결과에 1000을 곱하면 밀리초(ms) 단위로 변환할 수 있습니다.

파일 읽기, 배열 생성, 화면 출력 등은 MAC 연산 측정 시간에서 제외합니다.

📈 9. 측정 결과를 어떻게 분석할까요?

배열 크기가 커지면 계산해야 하는 MAC 연산 횟수가 증가합니다.

일반적으로 연산 횟수가 증가하면 실행 시간도 증가하는 경향이 있습니다.

3×3 배열: 9회
25×25 배열: 625회

필터 하나 기준 연산 횟수 증가 비율
625 ÷ 9 ≈ 69.44배

하지만 연산 횟수가 약 69.44배 증가한다고 해서 실제 실행 시간도 반드시 69.44배 증가하는 것은 아닙니다.

컴퓨터 성능, 메모리, 브라우저 최적화, 다른 프로그램의 실행 상태 등이 측정 결과에 영향을 줄 수 있습니다.

시간 복잡도는 반복문의 구조와 연산 횟수를 근거로 설명하고, 실행 시간은 실제 측정 결과를 통해 그 경향을 확인합니다.

🎯 10. 동료평가 예상 질문과 답변

Q1. 성능 분석이란 무엇인가요?

A. 프로그램의 연산 횟수와 실행 시간 등을 측정하고 분석하는 과정입니다.

Q2. O(N²)는 무엇을 의미하나요?

A. 배열 한 변의 길이가 N일 때 작업량이 N의 제곱에 비례하는 형태로 증가한다는 의미입니다.

Q3. 5×5 배열의 MAC 연산 횟수는?

A. 필터 하나를 기준으로 5 × 5 = 25회입니다.

Q4. 25×25 배열에서 필터 두 개를 비교하면?

A. 25 × 25 × 2 = 1,250회입니다.

Q5. 이중 반복문이 왜 O(N²)인가요?

A. 바깥 반복문이 N번 실행되고 각 실행마다 안쪽 반복문이 N번 실행되어 총 N²번 계산하기 때문입니다.

Q6. 실행 시간을 여러 번 측정하는 이유는?

A. 한 번의 측정에서 발생할 수 있는 시간 변동의 영향을 줄이고 평균 실행 시간을 확인하기 위해서입니다.

Q7. 파일 읽기 시간을 제외하는 이유는?

A. 파일 처리 시간이 아니라 MAC 연산 자체의 성능을 비교하기 위해서입니다.

Q8. 필터가 두 개이면 왜 O(2N²)가 아닌가요?

A. 실제 연산 횟수는 2N²이지만 시간 복잡도에서는 고정된 상수를 생략하므로 O(N²)로 표현합니다.

Q9. 실행 시간도 반드시 N²에 비례하나요?

A. 실제 실행 시간은 컴퓨터와 실행 환경에 영향을 받으므로 정확히 비례하지 않을 수 있습니다.
