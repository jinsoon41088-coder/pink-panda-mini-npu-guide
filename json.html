📚 1. JSON이란 무엇일까요?

JSON은 데이터를 일정한 규칙에 따라 저장하고 전달하는 텍스트 형식입니다.

JSON은 컴퓨터가 정보를 읽고 활용할 수 있도록 정리해 놓은 디지털 정보 노트라고 생각하면 됩니다.

🐼 판다 정보 노트
이름: 핑크판다
좋아하는 과일: 바나나
좋아하는 색상: 핑크색

JSON으로 표현하면?

{
    "name": "핑크판다",
    "fruit": "바나나",
    "color": "핑크색"
}

🔑 2. 키(Key)와 값(Value)

키는 정보의 이름이고, 값은 그 이름에 해당하는 실제 내용입니다.

키(Key) 값(Value)
name 핑크판다
fruit 바나나
color 핑크색
키 = 무엇에 대한 정보인지 알려주는 이름
값 = 실제로 저장된 정보

📂 3. Mini NPU의 data.json 구조

Mini NPU 미션에서는 JSON 파일을 이용하여 필터, 입력 패턴, 예상 정답 등을 관리합니다.

항목 의미
filters 비교할 기준 필터
patterns 테스트할 입력 패턴
input 입력 숫자 배열
expected 예상 정답 라벨

학습용 JSON 구조 예시

{
    "filters": {
        "size_3": {
            "cross": [
                [0, 1, 0],
                [1, 1, 1],
                [0, 1, 0]
            ],
            "x": [
                [1, 0, 1],
                [0, 1, 0],
                [1, 0, 1]
            ]
        }
    },
    "patterns": {
        "size_3_1": {
            "input": [
                [0, 1, 0],
                [1, 1, 1],
                [0, 1, 0]
            ],
            "expected": "+"
        }
    }
}

위 코드는 구조를 쉽게 이해하기 위한 3×3 배열 학습용 예시입니다. 실제 미션 데이터에는 5×5, 13×13, 25×25 등의 배열이 사용됩니다.

📏 4. data.json의 키 규칙

size_N = N×N 크기의 필터 그룹
size_N_idx = 크기와 테스트 번호
키 이름 배열 크기 번호
size_5_1 5×5 1번
size_13_2 13×13 2번
size_25_1 25×25 1번

프로그램은 키 이름에서 배열 크기를 확인하고 해당 크기의 필터를 찾아 비교합니다.

🏷️ 5. 라벨 정규화란 무엇일까요?

라벨은 데이터의 종류나 정답을 나타내는 이름입니다.

라벨 정규화는 같은 의미를 가진 서로 다른 표현을 하나의 표준 이름으로 통일하는 과정입니다.

🐼 panda, Panda, PANDA
모두 같은 판다를 나타낼 수 있지만 컴퓨터에서는 서로 다른 문자열입니다.
원본 라벨 정규화 결과
+ Cross
cross Cross
Cross Cross
x X
X X

UNDECIDED는 두 점수의 차이가 허용오차보다 작을 때 사용하는 별도의 판정 결과입니다.

💻 7. Python 코드로 이해하기

def normalize_label(label):

    if not isinstance(label, str):
        raise ValueError("라벨은 문자열이어야 합니다.")

    label = label.strip().lower()

    if label in ("+", "cross"):
        return "Cross"

    elif label == "x":
        return "X"

    elif label == "undecided":
        return "UNDECIDED"

    else:
        raise ValueError("지원하지 않는 라벨입니다.")

코드의 의미

isinstance(): 문자열인지 확인합니다.

strip(): 문자열 앞뒤의 공백을 제거합니다.

lower(): 영어 대문자를 소문자로 변환합니다.

return: 정규화된 결과를 반환합니다.

ValueError: 지원하지 않는 값이 들어오면 오류를 발생시킵니다.

⚠️ 8. 정규화가 필요한 이유

실제 판정 결과가 Cross이고 예상 정답이 +라고 가정해 봅시다.

정규화 전
Cross == + → False → FAIL
정규화 후
Cross == Cross → True → PASS

같은 의미의 정답이라도 문자열 표현이 다르면 잘못된 실패 판정이 발생할 수 있습니다.

따라서 비교하기 전에 라벨을 표준화해야 합니다.

단, 정규화는 잘못된 계산 결과를 올바른 정답으로 바꾸는 기능이 아닙니다.

🎯 9. 동료평가 예상 질문과 답변

Q. JSON이 무엇인가요?

A. 데이터를 일정한 규칙에 따라 저장하고 전달하는 텍스트 형식입니다.

Q. 키와 값의 차이는 무엇인가요?

A. 키는 정보의 이름이고, 값은 실제 저장된 정보입니다.

Q. size_13_2는 무엇을 의미하나요?

A. 13×13 크기의 두 번째 테스트 패턴을 의미합니다.

Q. 라벨 정규화란 무엇인가요?

A. 같은 의미를 가진 서로 다른 라벨을 하나의 표준 이름으로 통일하는 과정입니다.

Q. 라벨 정규화가 왜 필요한가요?

A. 같은 의미의 라벨이 서로 다른 문자열로 표현되어 잘못된 실패 판정이 발생하는 것을 방지하기 위해 필요합니다.

Q. 지원하지 않는 라벨은 어떻게 처리하나요?

A. 임의로 정답으로 변경하지 않고 오류로 처리하여 원인을 확인합니다.
