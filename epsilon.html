핑크판다 부동소수점과 epsilon 학습

컴퓨터의 작은 계산 오차를 이해해요!

📚 1. 부동소수점이란 무엇일까요?

부동소수점은 컴퓨터에서 소수나 매우 크고 작은 숫자를 표현하는 방식입니다.

🐼 부동소수점 숫자 예시
0.1
0.2
3.14
0.000001

컴퓨터는 제한된 공간에 숫자를 저장합니다. 따라서 일부 소수는 정확하게 저장하지 못하고 가장 가까운 값으로 표현합니다.

이러한 이유로 아주 작은 계산 오차가 발생할 수 있습니다.

🍰 2. 케이크로 쉽게 이해하기

핑크판다가 케이크 한 개를 세 친구에게 똑같이 나누어 준다고 생각해 봅시다.

🎂 ÷ 3
1 ÷ 3 = 0.333333...

소수점 아래 숫자 3이 끝없이 반복됩니다.

하지만 숫자를 저장할 수 있는 공간이 제한되어 있다면 모든 숫자를 저장할 수 없습니다.

0.333333 × 3 = 0.999999

원래 값인 1과 아주 작은 차이가 발생합니다.

이것은 제한된 자릿수 때문에 발생하는 오차를 이해하기 위한 비유입니다.

실제 컴퓨터의 일반적인 부동소수점 계산은 이진수 표현을 사용합니다.

🧮 3. 0.1 + 0.2 계산 실험

사람이 생각하는 계산 결과
0.1 + 0.2 = 0.3

컴퓨터의 실제 계산 결과

계산 버튼을 눌러주세요.

0.1과 0.2는 이진수 부동소수점으로 정확하게 표현하기 어려운 숫자입니다.

그래서 두 숫자를 더하면 0.30000000000000004처럼 아주 작은 오차가 나타날 수 있습니다.

📏 4. epsilon이란 무엇일까요?

epsilon은 두 숫자의 차이가 얼마나 작을 때 사실상 같은 값으로 취급할지 정하는 허용오차입니다.

미션의 기본 허용오차
epsilon = 1e-9
0.000000001

1e-9는 10의 마이너스 9제곱을 의미합니다.

두 점수의 차이가 이 값보다 작으면 Mini NPU 미션에서는 판정을 보류합니다.

⚖️ 5. Mini NPU의 판정 규칙

먼저 십자가 점수와 X 점수의 차이를 절댓값으로 계산합니다. 

difference = abs(score_a - score_b)
조건 판정 결과
점수 차이 < epsilon UNDECIDED
차이가 epsilon 이상이고 십자가 점수가 높음 Cross
차이가 epsilon 이상이고 X 점수가 높음 X
UNDECIDED는 두 점수의 차이가 너무 작아 어느 쪽인지 확실하게 판정하지 않는다는 의미입니다.

이 미션은 작은 차이를 비교할 때 < 연산자를 사용합니다.

계산된 점수 차이가 epsilon과 정확히 같다면 판정을 보류하지 않고 높은 점수를 선택합니다.

두 점수와 허용오차를 변경하면서 최종 판정 결과를 확인해 보세요.

③ 비교 결과

④ 최종 판정 결과

※ 이 계산기에서는 학습을 위해 epsilon 값을 변경할 수 있습니다. 실제 미션에서는 정해진 허용오차를 사용해야 합니다.

💻 7. Python 코드로 이해하기

def classify(score_a, score_b):

    epsilon = 1e-9

    difference = abs(score_a - score_b)

    if difference < epsilon:
        return "UNDECIDED"

    elif score_a > score_b:
        return "Cross"

    else:
        return "X"

코드의 의미

epsilon = 1e-9
허용오차를 설정합니다.

abs()
두 숫자의 차이를 음수가 아닌 값으로 계산합니다.

if
두 점수의 차이가 허용오차보다 작은지 확인합니다.

elif
판정을 보류할 조건이 아니라면 십자가 점수가 더 높은지 확인합니다.

else
앞의 조건에 해당하지 않으면 X로 판정합니다.

위 Python 함수는 유효한 유한 숫자 점수가 전달된다는 전제의 학습용 코드입니다.

📊 8. 판정 결과 예시

허용오차는 1e-9로 설정합니다.

Cross 점수 X 점수 결과
5 1 Cross
1 5 X
5 5 UNDECIDED
0.9 0.8999999999 UNDECIDED
1e-9 0 Cross

⚠️ 9. 허용오차를 사용할 때 주의할 점

허용오차가 너무 크면 서로 다른 점수도 같은 값처럼 처리할 수 있습니다.

허용오차가 너무 작으면 아주 작은 계산 오차에도 다른 값으로 판정할 수 있습니다.

따라서 미션에서 정한 epsilon 값을 일관되게 사용해야 합니다.

예상 정답: Cross
실제 판정: UNDECIDED
테스트 결과: FAIL

UNDECIDED는 올바른 판정 정책에 따라 발생할 수 있는 결과입니다.

그러나 예상 정답이 Cross 또는 X라면 실제 판정과 일치하지 않으므로 해당 테스트는 FAIL로 기록합니다.

테스트를 통과시키기 위해 임의로 예상 정답이나 허용오차를 변경하면 안 됩니다.

🎯 10. 동료평가 예상 질문과 답변

Q1. 부동소수점이란 무엇인가요?

A. 컴퓨터에서 소수와 매우 크거나 작은 숫자를 표현하는 방식입니다.

Q2. 부동소수점 오차는 왜 발생하나요?

A. 일부 소수를 제한된 이진수 자릿수로 정확하게 표현할 수 없기 때문입니다.

Q3. epsilon이란 무엇인가요?

A. 두 숫자의 차이가 얼마나 작을 때 같은 값처럼 취급할지 정하는 허용오차입니다.

Q4. 1e-9는 어떤 숫자인가요?

A. 0.000000001이라는 매우 작은 숫자입니다.

Q5. UNDECIDED는 무엇인가요?

A. 두 점수의 차이가 허용오차보다 작아 판정을 보류한다는 의미입니다.

Q6. abs()는 왜 사용하나요?

A. 어느 점수가 더 큰지와 관계없이 두 점수 사이의 차이 크기를 계산하기 위해 사용합니다.

Q7. epsilon과 점수 차이가 같으면 어떻게 되나요?

A. 이 미션은 미만 조건을 사용하기 때문에 계산된 차이가 epsilon과 정확히 같다면 더 높은 점수를 가진 모양으로 판정합니다.

Q8. UNDECIDED가 나오면 무조건 오류인가요?

A. 아닙니다. 판정 정책에 따른 정상적인 결과일 수 있습니다. 다만 예상 정답과 다르면 테스트는 실패로 기록합니다.
